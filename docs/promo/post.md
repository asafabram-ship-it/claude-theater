## English

Running several agents in parallel in Claude Code? A minute in, it's hard to tell who is doing what.

So we built Claude Theater: a pane beside the conversation in the Claude desktop app's Code tab that shows a live office of your agents.

🎭 A card per conversation, a row per agent: who's thinking, who's waiting, who's done
★ A mark and a sound the moment an agent finishes
⏳ The 5-hour usage meter in plain view
📌 Pin conversations; click a name to see its task and result

Free, open source, nothing leaves your machine. Hebrew and English.

Install in the app: + next to the prompt box → Plugins → Add marketplace → `legalmindcode/claude-theater` → Add plugin → `agent-theater`

Or in a terminal session:
```
/plugin marketplace add legalmindcode/claude-theater
/plugin install agent-theater@claude-theater
```
